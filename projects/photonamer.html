Photonamer

Python Vision Language Model CLI

A CLI tool that autonomously renames image files based on their date, subject, mood, and compositional technique — inferred by a vision language model.

OVERVIEW

Photonamer solves the problem of disorganised image libraries by automatically generating descriptive, human-readable filenames. Instead of IMG_4823.jpg, you get something like 2024-06_golden-hour-portrait_warm_rule-of-thirds.jpg.
