NeuralArt

FastAPI Next.js Celery Redis PostgreSQL DigitalOcean

A photo gallery app where users can apply artistic styles to their photographs using neural style transfer and store the results in their personal library.

OVERVIEW

NeuralArt lets users upload photographs and apply the visual style of famous artworks or custom style images to them using neural style transfer. The results are stored in a personal library that users can manage and revisit.

ARCHITECTURE

Async Processing with Celery — Neural style transfer is computationally expensive. Tasks are offloaded to Celery workers so style transfer runs asynchronously without blocking the API response. Redis acts as the Celery message broker.
